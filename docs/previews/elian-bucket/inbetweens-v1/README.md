# Zwischenposen: von der Hocke zum aufrechten Tragen

`Zwischenposen-Hocke-Tragen.png` zeigt vier neue Zwischenposen auf einer gemeinsamen Vergleichstafel:

1. Eimer löst sich vom Boden; Knie noch deutlich gebeugt, freie Hand am Oberschenkel.
2. Hüfte und Schultern steigen; Knie werden gestreckt, Griff bleibt am Holzhenkel.
3. Fast aufrechte Haltung; freie Hand verlässt den Oberschenkel, Eimer kommt an die Trageseite.
4. Aufrechte Tragehaltung mit breitem, stabilem Stand und entspanntem freien Arm.

Die bereits bestätigte Hocke und Tragepose aus `../poses-v1` dienen als Referenzen. Vier zunächst unabhängig gezeichnete Entwürfe hatten sichtbare Maßstabsabweichungen und wurden nicht ausgewählt. Die ausgewählte gemeinsame Tafel wurde gezielt bei Eimergröße und Standbreite überarbeitet. Kopfgröße, aufsteigende Körperhaltung, unveränderter Griff, Eimerform/-größe sowie verbundene Gliedmaßen wurden nebeneinander visuell geprüft. Die Tafel bleibt ein zeichnerischer Entwurf zur Beurteilung: Sie ist kein Nachweis pixelgenau gleicher Einzelteile und enthält noch keine registrierten oder zerlegten Animationsframes.

Erstellung mit dem eingebauten image_gen; die für das ausgewählte Bild verwendeten Prompts und Quellen stehen in `prompts.json`. Das generierte Original bleibt erhalten. Bestehende Posebilder bleiben unverändert.

In diesem Schritt wurden keine Unity-Szenen, Figurensteuerungen, Übergänge oder Spielaufträge geändert. Keine Animation und kein Build erstellt. Keine Laufzeittests für reine Bildvorlagen.
