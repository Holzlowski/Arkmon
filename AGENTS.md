## Character animation

Before modifying character poses, rigs, movement, carrying or interaction animation, read [docs/animation-workflow.md](docs/animation-workflow.md). The user explicitly requested that these lessons persist after repeated expensive animation repairs.

Use a consistent jointed figure and rigid prop. Show actual Unity static poses for visual feedback before implementing new transitions. Generated pictures are references, not Unity implementation evidence. Fixed contact/length tests are necessary mechanical checks and do not establish natural motion. Keep review work isolated from courtyard quest behavior until accepted. No test build unless asked.
